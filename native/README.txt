prism.dll in this folder is the official 64-bit Windows release build of Prism 0.18.2,
taken unmodified from https://github.com/ethindp/prism/releases/tag/v0.18.2
(file prism-windows-x64.zip, folder dynamic/release/bin).

Prism is licensed under the Mozilla Public License 2.0. Its source code is available at
https://github.com/ethindp/prism . The licenses folder holds Prism's license and the
licenses of the libraries built into it. These are copied next to the program when it is built.

It only needs files that come with Windows, so nothing else has to be installed for it.

**Adults only (18+).** Describer After Dark describes sexually explicit images in explicit detail.

First release.

- Press Control+Alt+D to describe the image or image link on your clipboard. Works with Luna for Reddit ("Copy post image link"), Reddit for Blind, web browsers, copied images, and image files.
- Speaks through NVDA, JAWS, and other screen readers, with follow-up questions about the picture.
- Runs entirely on your own computer through Ollama. No images are sent anywhere.

**To install:** download `DescriberAfterDark-1.0-win-x64.zip`, extract it, and run `DescriberAfterDark.exe`. On first launch it helps you install Ollama and download the description model (about 6 GB). Needs 64-bit Windows 10 or 11.
